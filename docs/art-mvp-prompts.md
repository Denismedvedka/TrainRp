## Порядок генерации персонажей

Для каждого персонажа: сначала портрет-эталон (промпт ниже), затем все следующие изображения этого персонажа — в том же чате, с явной ссылкой на эталон («тот же персонаж, что на предыдущем изображении»). Не открывать новый чат и не пересказывать словами — модель держит консистентность только по контексту чата.

Портреты: поясной кадр, лёгкий поворот на 3/4, взгляд в камеру, нейтральный тёмный фон вагона без деталей интерьера — рамка и ракурс одинаковые у всех пяти.

Фоны: горизонтальные, без людей.
